# Kickoff Clash V8 — Match Engine UI Pass 01

Date: 2026-08-09  
Branch: `agent/v8-me-ui-pass-01`  
Base: `claude/generated-tactical-window-6dxfay`

## Objective

Start moving the V8 calibration lab toward the actual Match Engine experience without changing gameplay, balance, sequencing or engine state.

The first pass is deliberately structural. The existing lab exposed calibration controls, aggregate totals, telemetry and the raw event log at the same visual priority as the match itself. That was useful during balance work but made the screen read like a diagnostic tool rather than a game.

## Pass 01 hierarchy

Default match hierarchy is now:

1. score / period / Energy
2. DEF / MID / ATT pitch
3. current decision / End Period control
4. hand
5. period recap
6. lab / calibration surfaces

The calibration surfaces remain available below the playable match:

- calibration squad selectors
- compressed Cost profiles
- raw ATT / DEF totals
- calibration telemetry
- match/action log

No test hooks or engine APIs were removed.

## Hand-card readability

Player hand cards now prioritise:

- Cost
- position
- player name
- Action name
- ATT / DEF

The full Action paragraph is visually suppressed in the compact match card. The existing text remains in the DOM and engine data; a later focused-card/detail UI should own full Action wording.

Tactical and Manager cards retain their explanatory text because they do not yet have a separate detail surface.

## Pitch / decision treatment

- pitch is visually promoted immediately below the score bar
- user and opponent halves are more distinct
- deployed player chips are denser and less visually dominant than hand cards
- opponent chips are deliberately subdued relative to the player's board
- the decision strip is compact and keeps End Period visually primary
- Generated-Tactical Window retains its existing interaction path and receives a distinct decision-state treatment

## Explicit non-goals

This pass does not change:

- player or Tactical values
- scoring
- Energy
- Action wording/data
- reveal order
- Generated-Tactical Window rules
- CPU behaviour
- period recap calculation
- telemetry calculation
- balance/reference squads

## Next UI slices

Recommended follow-up work after this hierarchy pass is validated:

1. replace real/full names with match names on compact deployed/hand surfaces
2. design focused-card interaction for full Action text and status detail
3. improve committed-play feedback on the pitch rather than relying on text in the decision strip
4. make zone strength / scoring consequence legible without exposing noisy raw calibration totals
5. replace remaining lab terminology in the default player-facing surface
6. evaluate whether the pitch/hand can stay fully usable without vertical scrolling on the target phone viewport once richer card art is restored
