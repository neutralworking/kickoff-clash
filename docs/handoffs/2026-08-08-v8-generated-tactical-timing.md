# V8 generated Tactical timing — resolved 2026-08-08

> **SUPERSEDED (2026-08-08) by `2026-08-08-v8-generated-tactical-window.md`.** The
> "banked for the next commitment window" rule below is no longer the behaviour: a
> Tactical generated during a period is now playable in that same period's post-reveal
> Generated-Tactical Window, in every period including P4. What survives unchanged:
> movement-generated Tacticals remain immediately playable during commitment,
> end-of-period generation still lands in the next period, and P4 end-of-period
> generation still fizzles at FT. Kept for history.

## Contract

V8 keeps **one commitment window per period**.

- A Tactical generated by an **On Reveal** effect is banked for the **next period's commitment window**.
- A Tactical generated by an **end-of-period** effect is available in the next period's commitment window.
- A Tactical generated by **movement during commitment** remains immediately playable that period. PENDOLINO is the canonical example.
- Reveal/end-of-period Tactical generation in **P4 fizzles at FT** because there is no later commitment window. The runtime emits an explicit event instead of leaving an unusable card in hand.
- Banked cards carry `availableFromPeriod`; canonical V8 play/spend wrappers reject early use.
- THREE LUNGS now reads in the V8 calibration surface: `On Reveal: Add a Trigger Press to your hand for next period. It costs 0.` The free period travels with the generated card to the first window in which it can actually be played.

This is now part of the playable V8 baseline rather than an open calibration question.

## Acceptance coverage

Tests prove BEND IT, PAUSE AND SLIP, KILLER PASS, Penalty generation and Baresi's Offside Trap obey the next-window rule; THREE LUNGS becomes free in its actual playable window; PENDOLINO remains immediately playable during commitment; and P4 generation fizzles cleanly.

## Calibration impact

Fixing timing before touching balance numbers materially improved Through Ball and reduced the first matrix's false Control dominance. The current final calibration baseline is documented in `docs/handoffs/2026-08-08-v8-calibration-matrix.md`.
