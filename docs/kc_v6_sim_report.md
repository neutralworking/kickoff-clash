## Known balance concerns (tuning is ongoing)

The model is **validated and responsive** — goals scale with the build, the decision
metrics (threshold-change, divergence) sit on target, and four tuning passes moved total
goals from ~17 to the current figure. It is **not yet at the D2 goal band**; documented gaps:

- **Total goals run hot** (~2× the 2.2–3.2 target). Three of four decks are already near
  target (aggressive/flexible/defensive); the remaining volume is chance-count driven — the
  ATT-plentiful pool keeps most sectors a threshold above the opposing DEF. Closing it needs
  more DEF-side mass (or a higher threshold, which the handoff pins at 5).
- **The `combo` deck over-converts** (faces + reroll stacking). Nerfed from 73%→~67% by
  dropping the last `all_in_sector` faces to `first_in_sector`; still above the 55% ceiling.
  This is the A2 skill lever working — it needs a cost, not removal.
- **Lead-stickiness is high** (>65%). This confirms the A1 review concern: with many goals the
  board-control priority rule lets the leader snowball. Worth revisiting once goals come down.

Next levers (for balance-lab / owner): raise DEF budget or reduce faces/reroll prevalence,
then re-check lead-stickiness. The vitest gate asserts sane bands + the skill gradient, not the
exact target, per the handoff ("Do not assert exact balance metrics in the first commit").
