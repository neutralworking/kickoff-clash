# Decision: live-match token silhouette

**Date:** 2026-07-29  
**Status:** locked  
**Parent spec:** `docs/player-card-system-spec.md`, section 11

The active live-match player uses a **compact vertical mini-card silhouette**.

It is not a circular portrait chip and it is not the complete 2:3 card blindly scaled down.

The token retains the recognisable card structure:

- small current-position badge
- cut-out head-and-shoulders portrait
- simplified KC monogram background
- chamfered surname nameplate
- angular ATT badge at bottom-left
- angular DEF badge at bottom-right
- subtle rarity edge/frame

The token removes information that is no longer actionable after the player is fielded:

- no energy-cost pips
- no permanent action panel
- no role/archetype
- no career record
- no full rarity label

Only the current effective ATT and DEF values are shown. A reduced value is red; an increased value is blue; an unchanged value is neutral.

Selection, event focus, substitution targeting, `OUT`, and `OOP` are contextual treatments outside the permanent token anatomy.

Exact dimensions remain subject to validation on the real mobile V7 pitch.
